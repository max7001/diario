Importazione & Esportazione Dati

Puoi importare il tuo archivio esportato da Diaro (file .TXT) oppure creare e ripristinare backup completi in formato JSON contenenti anche le immagini.

Importa da Diaro (.TXT)

Carica il file .TXT esportato da Diaro. Riconosce automaticamente date, titoli ::: Titolo :::, meteo e luoghi, separati dalla riga a 80 trattini.

Esporta in Diaro (.TXT)

Salva tutte le note correnti in un unico file compatibile con il formato Diaro (separatore 80 trattini).

Backup Completo (.JSON)

Include tutte le note, fotografie, meteo, cartelle e date.

Ripristina Backup (.JSON)

Carica un file di backup JSON per ripristinare il tuo archivio con foto.
